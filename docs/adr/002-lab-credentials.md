# ADR-002 — Local-only credentials are literal in the repo

**Status:** accepted · **Date:** 2026-08-29

## Context

`postgres` passwords and the `oracle_ro` role password appear literally in
`docker-compose.yml`, `apps/*/db.py` and `oracle/quiescence.py`. A security scan
flags this, correctly, as hardcoded credentials.

## Decision

Keep them literal, because of what they guard:

- every port binds to `127.0.0.1`, never `0.0.0.0`
- all three databases use `tmpfs` storage and hold nothing across a restart
- the only data is synthetic fixtures generated by the tests themselves
- the repo is public by design; a reader must be able to `make up` and reproduce
  the result without provisioning anything

Introducing a secrets mechanism here would add a moving part that makes
reproduction harder while protecting nothing.

## Boundary

This decision does **not** extend past Stage 0. The moment this lab talks to
anything real — a hosted database, a cloud deployment, any non-synthetic data —
these must move to environment configuration. Every DSN already reads an env var
first (`BILLING_DSN`, `LEDGER_DSN`, `CONTROL_DSN`, `BILLING_RO_DSN`,
`LEDGER_RO_DSN`), so the override path exists and is used by the manifest.
